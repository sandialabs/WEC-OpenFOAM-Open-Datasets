# Post-processing Scripts and Data

## 🛠️ Post-processing Scripts

- **extractMotion.sh**: Extracts motion (hull's CG) from the OpenFOAM `log.overInterDyMFoam` file  
  - Usage: `./extractMotion.sh OF_case_directory1/ OF_case_directory2/ ...`  
  - Output: `Motion.txt` will be placed inside each specified case directory.

- **extractForces.sh**: Extracts body forces from the OpenFOAM `log.overInterDyMFoam` file  
  - Usage: `./extractForces.sh OF_case_directory1/ OF_case_directory2/ ...`  
  - Output: `Forces.txt` will be placed inside each specified case directory.

- **extractTensions.sh**: Extracts restraint (mooring/tether) forces from the OpenFOAM `log.overInterDyMFoam` file  
  - Usage: `./extractTensions.sh OF_case_directory1/ OF_case_directory2/ ...`  
  - Output: `Tensions.txt` will be placed inside each specified case directory.

- **plotForces.py**: Plots total forces on the WEC from the `Output.txt` file generated by `extractForces.sh`  
  - Usage: `python plotForces.py OF_case_directory1/ OF_case_directory2/ ...`

- **plotMotion.py**: Plots the 6DoF motion from the `Output.txt` file generated by `extractMotion.sh`  
  - Usage: `python plotMotion.py OF_case_directory1/ OF_case_directory2/ ...`

- **plotTensions.py**: Plots the restraint tensions from the `Tensions.txt` file generated by `extractTensions.sh`  
  - Usage: `python plotTensions.py OF_case_directory1/ OF_case_directory2/ ...`
 
- **plot_free_decay.py**: Plots the 1‑DoF motion from the Motion.txt file generated by `extractMotion.sh`. The script also evaluates the damped frequency based on logarithmic decay. It can be used to calculate the natural frequency for benchmarking, ensuring that the values agree with the design state. In addition, it can plot results from multiple cases (e.g., different mesh resolutions) to perform a convergence check.  
  - Usage: `python plot_free_decay.py OF_case_directory1/ OF_case_directory2/ ...`

## 📦 Prepackaged Data

For each case, the following pre-run data are included:

- `Motion.txt`: Contains WEC motion time series.  
- `Forces.txt`: Contains time series of forces on the WEC.  
- `Tensions.txt` (if applicable): Contains restraint forces for cases with mooring systems.  
- 🎥 Video rendering of the simulation results.
