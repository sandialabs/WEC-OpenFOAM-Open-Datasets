## 3D OpenFOAM FSI Overset - Prescribed Oscillation Example Cases

### Cases
- 3D Reference Model 6 (RM6) oscillating in surge motion at 16 different frequencies
- Folder names indicate the oscillation period (in seconds) at full scale. The simulations, however, are performed using a 1:15 scaled model. 
- This example is designed to evaluate hydrodynamic coefficients across frequencies, specifically added mass and radiation damping
- The case emphasizes variation in frequency rather than different motion types
- For other degrees of freedom, the process is very similar and can be easily adjusted using the provided parameters

### Mesh files

For each case:
- Use `template_mesh_generation` with the provided `flowParams` and the CAD file in `<case>/constant/polyMesh.orig_gen_grid_files/` to generate the mesh.
- Some meshes are already provided in `examples_mesh_generation`.
- After generating the mesh at `<mesh_root>/caseMesh/finalMesh/constant/polyMesh/`, rename it to `polyMesh.orig` and place it in `<case>/constant/`.

### Setup
- **Single Processor**: Use the `Allrun.ser` script in each case to run on a single processing unit.
- **Multiple Processors**: Use the `Allrun` script in each case to run on multiple processing units.
    - For parallel runs, the number and type of domain decompositions can be adjusted in `<system>/decomposeDict`.

### Post-processing Scripts
- **extractForces.sh**: Extracts body forces from the OpenFOAM `log.overInterDyMFoam` file
    - Usage: `./extractForces.sh OF_case_directory1/ OF_case_directory2/ etc.`
    - Output: `Forces.txt` will be placed inside the specified OF_case_directory.
      
- **plotForces.py**: Plots total forces on the WEC from the `Output.txt` file generated by `extractForces.sh`
- Usage: `python plotForces.py OF_case_directory1/ OF_case_directory2/ ...`
    
### Prepackaged Data

- For each case, the following pre-run data are included:
    - `Forces.txt`: Contains WEC's body forces time series.
